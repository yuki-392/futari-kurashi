# PWAの検証手順

対象はPhase 1・項目1です。判断理由と結果は[実装記録0003](./implementation-log/0003-pwa-iphone.md)に残します。PCの検証結果とiPhone実機の結果を区別します。

## PC上で再現する

Node.js 24で、初回のみブラウザーを用意します。

```sh
npm ci
npx playwright install chromium
npm run check
npm run test:pwa
```

`test:pwa`は一時フォルダにビルドA/Bを作り、ローカルの同一URLで切り替えます。通常の`dist/`や公開中のURLは変更しません。Service Workerの登録・制御、静的ファイルのキャッシュ、オフライン再読み込み、更新の延期・再通知・適用、モバイル/PC幅の表示とブラウザーエラーを検査します。終了時にテスト用サーバーとブラウザーを閉じ、ビルド用一時フォルダを削除します。

画面キャプチャはOSの一時フォルダ内の`futari-pwa-evidence/`に保存します。保存先は実行ログに表示します。iPhone Safari・ホーム画面への追加・standalone起動の代わりとなるテストではありません。

## ビルド識別子

`VITE_APP_BUILD_LABEL`は公開される識別子です。未設定または空白の場合、package.jsonのバージョンを表示します。編集後は再起動・再ビルドが必要です。

```sh
VITE_APP_BUILD_LABEL=pwa-check-a npm run build
```

## 検証用URLへの公開

専用プロジェクトは`futari-kurashi-5fcab9`、チャネルは`pwa-check`です。

```sh
npm run firebase -- hosting:channel:deploy pwa-check --expires 7d --project futari-kurashi-5fcab9 --no-authorized-domains
```

現在はビルドBを公開中、有効期限は**2026-10-26 12:31（日本時間）**です。今後の期限は公開時のCLI出力と[実装記録0003](./implementation-log/0003-pwa-iphone.md)で確認します。`--no-authorized-domains`により、今回の検証ではAuthenticationのドメイン設定を変更しません。Firestoreルールや本番チャネルにもデプロイしません。

## iPhoneでビルドAを確認する

1. iPhoneの機種とiOSバージョンを控えます。
2. 案内された検証用HTTPS URLをSafariで開きます。
3. 画面下までスクロールし、フッターの`pwa-check-a`を確認します。
4. 共有メニューから「ホーム画面に追加」を選びます。iOSの表示に応じて「Webアプリとして開く」を有効にします。
5. 追加された名前・アイコンを確認し、ホーム画面のアイコンから起動します。Safariのアドレスバーがない独立表示を確認します。
6. 起動した状態で少し待ってから、一度アプリを終了し、ホーム画面から再起動します。
7. 起動済みの画面を確認した後、Wi-Fiとモバイル通信を両方オフにし、終了・再起動して確認画面が表示されるか確認します。その後通信を戻します。
8. 結果をチャットで伝えてください。ここまで終わる前にビルドBへ切り替えないでください。

オフラインでのデータ編集は対象外です。OSによるキャッシュ削除後や初回アクセス時のオフライン表示も保証しません。

## ビルドBで更新を確認する

ビルドAの導入をユーザーが確認後、Codexが次を実行済みです。既存のホーム画面アイコンから開き、以下の更新確認を行います。

```sh
VITE_APP_BUILD_LABEL=pwa-check-b npm run build
npm run firebase -- hosting:channel:deploy pwa-check --expires 7d --project futari-kurashi-5fcab9 --no-authorized-domains
```

1. ホーム画面からアプリを開くか、バックグラウンドから戻します。
2. 更新通知が出たら「あとで」を選び、`pwa-check-a`のままであることを確認します。
3. 一度別のアプリに切り替えてから戻り、更新通知の再表示を確認します。
4. 「更新する」を選び、再読み込み後のフッターが`pwa-check-b`になることを確認します。
5. 終了・再起動してもビルドBが表示されることを確認します。

通知が出ない・画面が表示されない場合は、その時点のビルド識別子と操作を伝えてください。問題を切り分ける前に、ホーム画面のアプリやSafariのサイトデータを削除する必要はありません。
