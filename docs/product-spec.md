# ふたりの暮らし（Futari Kurashi）製品仕様

**家事も、お金も、ふたりで。**

初版: 2026-10-19。ユーザー提供の企画・要件を保存した文書です。以下はアプリの目標仕様であり、実装済みの機能一覧ではありません。実装状況は [開発計画](./roadmap.md) を参照してください。

## 1. アプリ概要

「ふたりの暮らし」は、同棲カップル向けの生活管理Webアプリです。家事・掃除・断捨離・買い物・家計管理・生活ルールを1つのアプリで管理し、2人の生活をより快適で効率的にすることを目的とします。

| 項目         | 内容                                                                            |
| ------------ | ------------------------------------------------------------------------------- |
| アプリ名     | ふたりの暮らし                                                                  |
| リポジトリ名 | `futari-kurashi`                                                                |
| アプリ形式   | PWA（Progressive Web App）                                                      |
| 対応端末     | iPhoneを優先。将来的にAndroid・PCも対応可能                                     |
| 利用人数     | 2人                                                                             |
| 初期費用     | 0円                                                                             |
| 月額費用     | 無料枠内で0円                                                                   |
| データ管理   | クラウド保存・リアルタイム同期                                                  |
| 配布方法     | URLからアクセスし、ホーム画面に追加                                             |
| リポジトリ   | GitHub Private（目標。ローカルGit初期化だけでは非公開リポジトリは作成されない） |

### 解決したい課題

- 部屋に物が多く、生活スペースが狭い。
- 不用品や服が散らかりやすい。
- 掃除を定期的に行う習慣がない。
- 日用品の在庫を把握できず、買い忘れが発生する。
- コバエやアリなどの虫対策が十分ではない。
- デスクワーク環境が整っていない。
- 生活に必要な買い物や支出を計画的に管理したい。
- 2人の家事分担や生活ルールを明確にしたい。

## 2. 機能一覧

### ① ホーム・ダッシュボード

アプリを開いたときに、生活状況をまとめて確認できる画面。

- 今日のToDo一覧
- 今週の家事予定
- 家事の完了率
- 買い物リストの未購入件数
- 今月の支出合計と予算残額
- 直近の予定・お知らせ

家計に関する表示はPhase 2で追加します。

### ② ToDo・家事管理

日常の掃除や片付けをタスクとして管理する機能。

- タスクの追加・編集・削除
- 担当者の設定（自分・相手・2人）
- 期限・優先度の設定
- 毎日・毎週・毎月の繰り返しタスク
- 完了チェック
- タスクのカテゴリ分け
- 家事の実施履歴
- 担当者別の完了状況

### ③ 掃除スケジュール

掃除を習慣化するためのスケジュール管理機能。

- 曜日別の掃除予定
- 掃除場所ごとのタスク登録
- 掃除頻度の設定
- 担当者の交代・ローテーション
- 今日・今週の掃除一覧
- 掃除の完了記録

### ④ 買い物リスト

食品・日用品・家具などの購入予定を2人で共有する機能。

- 買うものの追加・編集・削除
- カテゴリ分け（食品・日用品・家具など）
- 数量・予算・優先順位の設定
- 購入済みチェック
- 購入担当者の設定
- 定期的に買う商品の管理
- 家計簿への支出登録（Phase 2の家計管理と連携）

### ⑤ 断捨離・持ち物管理

不用品を減らし、部屋のスペースを確保するための機能。

- 処分候補リストの作成
- 「捨てる・売る・譲る・保留」の分類
- 処分期限の設定
- 物の所有者の登録
- 処分完了チェック
- 処分した物の履歴
- 買い替え候補の管理

### ⑥ 家計管理

2人の生活費を可視化し、無理のない支出管理を行う機能。

- 収入・支出の手動登録
- 食費・日用品・家具などのカテゴリ管理
- 月間予算の設定
- カテゴリ別の予算管理
- 今月の支出合計・残額表示
- 支払った人の記録
- 支出ごとの負担割合の設定
- 2人の立替金・精算金額の自動計算
- 月別の支出履歴
- グラフによる支出の可視化（分析機能はPhase 3）

銀行口座・クレジットカードとの自動連携は初期版では対象外です。

> **段階実装メモ（Phase 2・項目1）:** 初期段階では収入・支出の記録、標準/世帯カテゴリ管理、月別明細と合計までを実装します。月間予算・カテゴリ別予算・支払者/負担割合・立替精算・買い物連携は後続項目として扱います。現在の実装状況は[開発計画](./roadmap.md)を参照してください。

### ⑦ 家のルール管理

2人で決めた生活ルールを記録・共有する機能。

- ルールの追加・編集・削除
- カテゴリ別のルール整理
- 2人の合意状況の記録
- ルールの変更履歴
- ルールの見直し

### ⑧ アカウント・共有設定

2人がそれぞれのiPhoneで安全にアプリを使用するための機能。

- メールアドレス・パスワードによる新規登録・ログイン
- 確認メールによるメールアドレス確認（確認後にアプリへ進む）
- パスワードを忘れた場合のメールによる再設定
- 個別のユーザーアカウント
- 世帯の作成・招待・参加
- 2人のデータ共有
- リアルタイム同期
- 世帯メンバー以外のアクセス制限
- ログアウト

## 3. 技術スタック

| 分類           | 技術                    | 用途                         |
| -------------- | ----------------------- | ---------------------------- |
| フロントエンド | React                   | UI・コンポーネント開発       |
| 開発言語       | TypeScript              | 型安全なアプリケーション開発 |
| ビルドツール   | Vite                    | 開発環境・本番ビルド         |
| CSS            | Tailwind CSS            | レスポンシブデザイン         |
| PWA            | vite-plugin-pwa         | ホーム画面への追加・アプリ化 |
| 認証           | Firebase Authentication | ログイン・ユーザー管理       |
| データベース   | Cloud Firestore         | データ保存・リアルタイム同期 |
| ホスティング   | Firebase Hosting        | Webアプリの公開              |
| バージョン管理 | Git                     | ソースコードの変更履歴       |
| リポジトリ管理 | GitHub                  | ソースコードの保管・管理     |

### 技術選定の方針

- **無料運用:** Firebase Sparkプランの無料枠内で動作させる。
- **シンプルな構成:** 専用のバックエンドサーバーを設置しない。
- **スマホファースト:** iPhoneでの操作性を最優先する。
- **リアルタイム性:** 2人の更新内容を即座に同期する。
- **セキュリティ:** Firebase AuthenticationとFirestore Security Rulesでアクセスを制御する。
- **拡張性:** 機能を段階的に追加できる構成にする。

無料枠の上限やサービス仕様は変更され得るため、導入・公開時に公式情報と使用量を確認します。現段階ではCloud Functions、Cloud Storage、外部の有料APIを導入しません。

## 4. 画面構成

| 画面   | 内容                             |
| ------ | -------------------------------- |
| ホーム | ダッシュボード・今日の予定       |
| 家事   | ToDo・掃除スケジュール           |
| 買い物 | 共有買い物リスト                 |
| 片付け | 断捨離・持ち物管理               |
| 家計   | 支出・予算・精算                 |
| 設定   | 家のルール・アカウント・共有設定 |

iPhoneの画面下部に主要機能へのナビゲーションを配置し、片手でも操作しやすいデザインを目指します。6画面を維持したうえで、表示するタブ数・「その他」への集約などの詳細は画面設計時に決めます。

## 5. 開発フェーズ

### Phase 1：MVP（最小実用版）

- PWA対応
- ログイン・2人のデータ共有
- ホーム画面
- ToDo管理
- 掃除スケジュール
- 買い物リスト
- 断捨離リスト

### Phase 2：生活管理機能の充実

- 家計簿
- 月間予算管理
- 立替金の精算
- 家のルール管理

### Phase 3：利便性・分析機能

- 家事達成率のグラフ
- 支出分析グラフ
- 家事・支出の履歴分析
- CSV / JSON形式でのデータエクスポート
- バックアップ・データ復元の仕組み

### 将来の追加候補

- プッシュ通知・リマインダー
- 日用品の在庫管理
- 家具・衣類の買い替え時期通知
- カレンダー表示
- ダークモード
- 写真付きの持ち物管理（無料運用条件を再検討）

## 6. 非機能要件

| 項目           | 要件                                                 |
| -------------- | ---------------------------------------------------- |
| 操作性         | iPhoneで片手操作しやすいUI                           |
| パフォーマンス | 軽量で素早く画面が切り替わる                         |
| データ同期     | 2台のiPhoneでリアルタイム共有                        |
| セキュリティ   | 認証・世帯単位のアクセス制御                         |
| 費用           | 初期費用0円・月額無料枠内                            |
| 保守性         | 機能を独立したコンポーネントで管理                   |
| データ保護     | 定期的にエクスポートできる設計                       |
| ネットワーク   | 原則オンライン利用。一部オフライン対応は段階的に検討 |
| 拡張性         | 機能追加時にも既存データを維持できる構成             |

## 7. アプリの最終目標

単なるToDoアプリや家計簿ではなく、**2人の暮らしに必要な情報を一元管理できる生活プラットフォーム**を目指します。

日々の片付けや掃除を習慣化し、不要な物を減らし、買い物とお金を計画的に管理することで、2人が快適に暮らせる環境を作ります。
