# ホーム・ナビゲーションの確認

Phase 1・項目6。[実装記録0008](./implementation-log/0008-home-navigation.md)に理由・公開情報・実行結果を残します。

## 表示範囲

- 所属後はホーム・家事・買い物・片付け・家計・設定を下部ナビゲーションから切り替える。
- ホームの世帯名・人数・参加状況は既存のFirestore購読を共有する。1人の作成者は設定から相手を招待できる。
- 未実装のデータは準備中と表示し、取得していない件数や金額を表示しない。家計はPhase 2。
- 認証・メール確認・世帯未所属・所属確認中・取得失敗時は準備画面を表示する。
- 設定はメール・世帯・既存招待・ログアウト。画面を離れると招待フォームの入力・確認結果を破棄する。

## ローカル検証

npm run check、npm run test:integration、npm run test:pwaを実行する。統合テストはdemo-futari-kurashiの架空アカウントのみを使い、実メールを送信しない。

ハッシュは#/home、#/chores、#/shopping、#/declutter、#/finances、#/settings。不明なハッシュはホームへ戻る。URLへコードやメールを載せない。既存ログイン状態での直接アクセス・再読み込みは画面を維持し、ログアウト・アカウント変更時はホームへ戻る。

既存のテスト用アカウントと世帯を使い、iPhoneで次を確認する。今回、新しい世帯を作る必要はない。

1. 既存ホーム画面アプリを更新し、最下部がhome-checkになる。ホームに既存世帯・2人表示が出る。

4. 設定を開いたままアプリを終了・再起動し、同じ画面と所属が維持される。
5. 設定からログアウトすると世帯情報が消える。同じアカウントへ再ログインするとホームと元の所属へ戻る。
