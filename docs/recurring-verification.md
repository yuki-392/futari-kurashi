## 動作とローカル検証

- 家事はToDo/繰り返し/履歴。初期表示はToDoで、通常ToDoの保存形式と完了済み一覧を維持する。
- 毎日/毎週/毎月、未完了1件持ち越し。週は開始曜日、月は開始日の日付（存在しない月は末日）を維持し、完了後に元の周期の次回へ進む。
- 履歴の完了を記録した本人と担当は別の情報。取り消せるのは、その後の完了・編集・停止再開がない直近1回だけ。取消済み履歴も残す。
- 設定保存は次回予定を確認し、以前の取消参照を破棄する。停止・再開では未完了予定を保持する。定義削除・通常ToDoの履歴追加は今回対象外。
- 定義/履歴100件、ホーム10件ずつ。履歴に対応する現行定義をIDごとに重複なく購読し、取消できる行だけボタンを出す。画面を離れると解除する。
- npm run check、npm run test:recurring、npm run test:integration、npm run test:pwa。架空のdemoプロジェクトとメールだけを使う。

## 本人のiPhone＋Mac確認

既存の別々の確認済みテストアカウント・同じ世帯を使い、新しい世帯を作らない。パスワード・コードの送付は不要。

1. 両端末をrecurring-checkへ更新する。iPhoneの家事→繰り返しで「共有確認用の片付け」を毎日・開始日＝今日・担当＝相手で登録し、Macのホーム「今日・持ち越しの家事」に再読み込みなしで出ることを確認する。担当はiPhoneで相手、Macで自分。
2. Macで完了する。iPhoneの繰り返し一覧が次回＝明日となり、履歴に今日の予定日・完了日時・記録者＝相手が出る。ホームの対象からは消える。
3. iPhoneの履歴で直近の完了を取り消す。両方のホームに元の予定が戻り、履歴は取消済みとして残る。再度Macで完了すると新しい履歴が増え、その1件だけ取り消せる。
4. iPhoneで設定を編集し、タイトルと次回予定＝今日を確認して保存する。以前の完了の取消ボタンがなくなり、Macにも変更が反映する。一時停止するとMacのホームから消え、再開すると保持していた今日の予定に戻る。
5. 両端末を終了・再起動し、家事→繰り返し/履歴を開いて同じ内容が残ることを確認する。片方のログアウトで非表示となり、同じアカウントで再ログインして元の一覧と履歴を取得できることも確認する。
