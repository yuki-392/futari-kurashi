# 家計・収入/支出記録の確認手順

対象はPhase 2・項目1です。検証公開は [pwa-check](https://futari-kurashi-5fcab9--pwa-check-uol8w76f.web.app) の `finance-check`（Hosting version `186199409d859a57`、期限2026-10-28 13:34 JST）。previewは実際のFirebase Auth/Firestoreを使い、本番と同じアカウント・世帯データを参照します。実生活の金額は入力せず、既存のテスト用2アカウントで架空の確認明細だけを使用してください。期限切れ後もFirestore内の明細・Rules・インデックスは残ります。

## 確認項目

1. iPhoneとMac/Chromeを同じテスト世帯の別アカウントで `finance-check` に更新し、家計画面を開く。初期カテゴリが収入3種・支出10種表示される。
2. 一方で架空の支出を登録し、もう一方で再読み込みなしに明細と支出合計が更新されることを確認する。反対側から収入を登録し、収入合計も反映する。
3. 明細を編集し、金額・日付・カテゴリ・メモが両方へ反映される。削除のキャンセルでは残り、確定後は両方から消える。
4. 月移動で対象月の明細と合計に切り替わり、前月/翌月へ再度移動できる。
5. 独自カテゴリを追加・名称変更・アーカイブする。既存明細はアーカイブ後も分類名が表示され、新規入力では選べない。再読み込み後もカテゴリ状態が維持される。
6. ログアウトで家計データが画面から消え、同じ確認用アカウントへのログイン後に世帯データへ戻る。

金額・パスワード・メール内確認リンク・招待コードをチャットや記録に貼らないでください。確認結果と端末/ブラウザー情報だけを共有してください。
