## 動作とローカル検証

- 未購入/購入済み。食品・日用品・家具・家電・その他のカテゴリを指定・絞り込みできる。
- 数量は正数・小数3桁・最大999999.999、10進文字列へ正規化。単位は10文字まで・空欄可。予算は項目全体の整数円/null（0〜999999999）、数量を掛けず実際の支出は登録しない。
- 担当は未担当/自分/相手/2人。どちらも編集・購入/解除・確認付き削除ができる。削除は完全削除で、履歴/削除取消はない。
- 未購入は優先度の高い順、同じ優先度なら新規順。購入済みは更新の新しい順。カテゴリはサーバー側で絞り込み、一覧100件ずつ。ホームは未購入を最大5件、続きは「ほかにもあります」。正確な総件数・予算合計は表示しない。
- transactionの版照合で古い編集・購入・削除を拒否し、入力を保持する。通信断時は書き込まずオンライン復帰後に再試行する。不要購読と認証/世帯変更時の入力/表示を破棄する。
- npm run check、npm run test:shopping、npm run test:integration、npm run test:pwa。Emulatorの架空アカウントだけを使う。直接改ざん・他世帯・競合は自動テストで検証する。
