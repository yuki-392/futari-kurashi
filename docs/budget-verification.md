# 月間・カテゴリ別予算の確認手順

Phase 2・項目2。実装・自動検証・検証公開・本人確認済み。[検証URL](https://futari-kurashi-5fcab9--pwa-check-uol8w76f.web.app)でbudget-checkへ更新する。Hosting version 0e4cdcf8cf4a85f9、期限2026-10-29 09:20 JST。公開情報/最終結果は[記録0019](./implementation-log/0019-budgets.md)に追記する。

## 仕様

- 月全体とカテゴリ別は独立した予算。未設定と0円は別。収入は支出実績から控除しない。
- 超過しても支出は登録できる。カテゴリ合計と月全体予算の一致は不要。
- 設定解除は予算だけを削除し、明細は保持する。
- 前月コピーは未設定だけを対象ごとに保存。途中失敗は件数を報告し、同じボタンで未設定だけ再試行する。
- アーカイブカテゴリは既存予算/実績の表示と解除のみ可能。新規設定・編集・コピーから除く。

## 自動検証

`npm run check`、`npm run test:finance`、`npm run test:integration`、`npm run test:pwa`。全統合には予算Rulesと2ブラウザーが含まれる。Emulatorはdemo-futari-kurashiを使い、クラウドに自動ユーザー作成・メール送信・テストデータ書き込みはしない。

## 本人確認

公開後に既存のテスト用2アカウント・テスト世帯を使用する。previewも本番と同じFirestoreで、予算や明細は7日期限後も残る。既存データは削除せず、確認用の架空金額だけを使う。

1. iPhone＋Mac／Chromeで検証URLをbudget-checkへ更新し、家計→予算を開く。
2. iPhoneで今月の月予算と食品等のカテゴリ予算を独立に設定し、Macへ画面遷移・再読み込みなしで反映されることを確認。
3. 片方をホームで開いたまま、もう片方で今月の架空支出を追加・編集・削除し、支出と残額が更新されることを確認。超過表示でも登録できること、0円設定と設定解除を区別できることも確認。
4. 前月へ移動して予算を設定し、今月へ戻ってコピー。今月設定済みの値/0円は変わらず、未設定部分だけが埋まり、再度コピーしても重複しないことを確認。
5. カテゴリ名変更・アーカイブ後も既存予算/実績を確認でき、新規設定から外れることを確認。設定解除をキャンセルすると残り、確定すると予算だけ消えることを確認。
6. 再起動後も予算を維持し、一方のログアウトで家計表示が消え、再ログインで元の世帯へ戻ることを確認。

日本時間の月境界・日付変更、上限、改ざん、同時操作は自動テストで確認し、実機で長時間待機しない。パスワード・メール内のコード・実生活の金額をチャットや記録へ送らない。
